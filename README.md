# Реализация SHA256withRSA в Android

## Описание проекта
Приложение демонстрирует работу асимметричного шифрования RSA в связке с хеш-функцией SHA-256 для создания и проверки электронной цифровой подписи

## Использованные технологии
* Kotlin
* Android SDK
* Jetpack Compose

## Как протестировать

Можно запустить проект локально через Android Studio или установить готовый APK-файл на свой смартфон:

1. В раздел **[Releases](https://github.com/ekzw/android-sha256-rsa-signature/releases)** на панели справа
2. Найти последнюю версию и в блоке **Assets** скачайте файл `app-release.apk`
3. Установить APK на Android-устройство
